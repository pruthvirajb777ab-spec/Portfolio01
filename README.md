# Pruthvi | Personal Portfolio

A futuristic black and dark-purple portfolio for a first-year Computer Science Engineering student at New Horizon College of Engineering, Bengaluru.

Built with plain HTML, CSS and JavaScript. No frameworks, no paid services.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Page content and sections |
| `style.css` | Colors, fonts, layout, animations |
| `script.js` | Loader, cursor, scroll reveal, 3D effects, menu |
| `cv.pdf` | Your CV (you add this file) |

## Edit your details

1. **Contact links**: in `index.html`, find the `Contact` section and replace `your-email@example.com` and the LinkedIn, GitHub and Instagram links with your own.
2. **Projects**: each project is an `<article class="card">`. Change the text, and replace the GitHub link.
3. **Project images**: upload an image to the repository, then replace `<div class="thumb">...</div>` with `<img class="thumb" src="image-name.jpg" alt="Project name">`.
4. **Skill levels**: skills show a neutral animation by default. To show your own level, add `data-level="70"` to the skill's `<article>`.
5. **CV**: upload a PDF named exactly `cv.pdf` to the repository.
6. **Colors**: change the values at the top of `style.css` under `:root`.

## Publish with GitHub Pages

1. Create a public repository named `portfolio` (or `yourusername.github.io` for a root address).
2. Upload all four files plus `cv.pdf`.
3. Go to **Settings > Pages**, set **Source** to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then **Save**.
4. After 1 to 2 minutes your site is live at `https://yourusername.github.io/portfolio/`.
